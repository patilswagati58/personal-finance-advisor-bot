# Finora — Personal Finance Advisor Bot

A responsive, frontend-only personal finance dashboard built with HTML, CSS, and vanilla JavaScript.

## Included modules
1. **Overview dashboard** — income, expenses, balance, savings rate, spending chart, and quick insights.
2. **Transactions** — add income/expenses, categorize, search/filter, and delete entries.
3. **Budget planner** — set a monthly limit and compare spending across categories.
4. **Savings goals** — create targets, track saved amounts, and add savings.
5. **AI-style advisor** — instant rule-based suggestions and a simple financial health indicator.
6. **Reports** — income/expense chart, category breakdown, and CSV export.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Start adding transactions or adjust the sample data.

No backend, Python, database, API key, or installation is required. Internet is used only for the Google font and Chart.js CDN; the rest of the website runs in the browser.

## Important limitations
- This is a demonstration project, not a bank-connected financial service.
- Data is saved in browser `localStorage` on this device/browser only. Clearing browser data or switching devices can remove it.
- The advisor uses simple rules, not a live AI model. It is not professional financial advice.
- The included transactions are sample data. Reset them using **Reset demo data**.

## Publish online (optional)
Upload `index.html`, `style.css`, and `app.js` to a static hosting service such as GitHub Pages or Netlify. No server is required.
